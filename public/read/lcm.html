最小公倍数的定义（定义 1.4.1）

◆ p.398-400｜1.4.2 最小公倍数

课件给出定义 1.4.1：设 a1,a2,…,ana_1, a_2, \ldots, a_na1​,a2​,…,an​ 是 nnn 个整数，若整数 DDD 是这 nnn 个数中每一个的倍数（即 ai∣Da_i \mid Dai​∣D 对每个 iii 成立），则 DDD 叫做这 nnn 个数的一个公倍数。在所有公倍数中，最小的那个正整数叫做最小公倍数，记作 [a1,a2,…,an][a_1, a_2, \ldots, a_n][a1​,a2​,…,an​]。

两个要点要咬住：一是"公倍数"可以是负数也可以是零（000 是任何非零整数的倍数），但"最小公倍数"必须在正整数里挑最小的，所以最小公倍数总是正的；二是定义要求每个 aia_iai​ 都整除 DDD，缺一不可。

课件用例 3 演示：整数 888 和 121212 的公倍数为 ±24,±48,±72,±96,…\pm 24, \pm 48, \pm 72, \pm 96, \ldots±24,±48,±72,±96,…（当然还有 000），其中最小的正整数是 242424，所以 [8,12]=24[8, 12] = 24[8,12]=24。注意 888 的倍数里没有 242424 以下的正数与 121212 的倍数重合：121212 的正倍数是 12,24,36,…12, 24, 36, \ldots12,24,36,…，其中第一个也是 888 的倍数的就是 242424。

◆ p.401-402｜数学描述

课件把定义翻译成集合语言：aaa、bbb 的最小公倍数 D=[a,b]D = [a, b]D=[a,b] 是集合 {E∣E∈Z, a∣E, b∣E}\{E \mid E \in \mathbb{Z},\ a \mid E,\ b \mid E\}{E∣E∈Z, a∣E, b∣E} 中的最小正整数；推广到 nnn 个数，DDD 是集合 {E∣E∈Z, ai∣E, 1≤i≤n}\{E \mid E \in \mathbb{Z},\ a_i \mid E,\ 1 \le i \le n\}{E∣E∈Z, ai​∣E, 1≤i≤n} 中的最小正整数。

这个集合式描述在后面的证明里非常有用：要验证某个 DDD 是最小公倍数，只需验证两件事——DDD 本身是公倍数（在集合里且为正），以及任何公倍数都不小于它。p.448 的等价刻画会把这两件事精确化。

拓展（课件外补充）：为什么"最小的正公倍数"一定存在？因为 ∣ab∣|a b|∣ab∣（a,ba,ba,b 非零时）就是一个正的公倍数，所以正公倍数集合非空；非空的正整数集合必有最小元（良序原理）。这也是后面所有"最小公倍数存在"论证的隐含依据。另外，若某个 ai=0a_i = 0ai​=0，则公倍数 DDD 必须满足 0∣D0 \mid D0∣D，按本章约定这只能在 D=0D = 0D=0 时成立，此时不存在正公倍数，最小公倍数无定义——课件习题里"对任意整数 mmm，m[0]m[0]m[0] 型表达式不存在"就是这个意思。

课前的两个练习

◆ p.403｜填空题

题目：对任意非零整数 aaa、bbb， （1）(a,b)×[a,b]=(a, b) \times [a, b] =(a,b)×[a,b]= 填空 1； （2）当 m>0m > 0m>0 时，(ma,mb)=m(a,b)(ma, mb) = m(a, b)(ma,mb)=m(a,b) 是否正确？ （3）当 m>0m > 0m>0 时，[ma,mb]=m[a,b][ma, mb] = m[a, b][ma,mb]=m[a,b] 是否正确？

解答：（1）填 ababab（当 a,ba, ba,b 都是正整数时）。理由将在 p.444 的定理 1.4.5(2) 严格证明：[a,b]=ab(a,b)[a, b] = \dfrac{ab}{(a, b)}[a,b]=(a,b)ab​，移项即得 (a,b)(a,b)(a, b)(a, b)(a,b)(a,b) 与 [a,b][a, b][a,b] 的乘积等于 ababab。注意题目说的是"非零整数"，若 aaa 或 bbb 为负，正确通式应带绝对值：(a,b)[a,b]=∣ab∣(a, b)[a, b] = |ab|(a,b)[a,b]=∣ab∣，因为最大公因数与最小公倍数都取正值。（2）正确：把 a,ba, ba,b 同乘 mmm，公因数整体放大 mmm 倍，最大公因数也放大 mmm 倍。（3）同样正确：同乘 mmm 后每个公倍数都放大 mmm 倍，最小公倍数随之放大 mmm 倍。这两条缩放规则的严格证明在 p.425-427 与 p.449-452。

◆ p.404｜多选题

题目：设 aaa、bbb 是两个互素的正整数，m>0m > 0m>0，以下哪些说法正确？ A. 若 a∣bca \mid bca∣bc，则 a∣ca \mid ca∣c； B. 若 a∣Da \mid Da∣D、b∣Db \mid Db∣D，则 ab∣Dab \mid Dab∣D； C. (a,b)=1(a, b) = 1(a,b)=1，[a,b]=ab[a, b] = ab[a,b]=ab； D. (ma,mb)=m(ma, mb) = m(ma,mb)=m，[ma,mb]=mab[ma, mb] = mab[ma,mb]=mab。

解答：四个选项都正确。A 是"互素消去律"（第一章 1.3 节定理 1.3.8 类结论）：a∣bca \mid bca∣bc 且 (a,b)=1(a, b) = 1(a,b)=1 时可把 bbb 约去。B 与 C 正是本课定理 1.4.4 的两条。D 是把 B、C 各放大 mmm 倍：(ma,mb)=m(a,b)=m(ma, mb) = m(a, b) = m(ma,mb)=m(a,b)=m，[ma,mb]=m[a,b]=mab[ma, mb] = m[a, b] = mab[ma,mb]=m[a,b]=mab。这道题其实就是定理 1.4.4 及其推论的预告，带着它去听证明会更清楚每条在什么条件下成立——关键前提"a,ba, ba,b 互素"不能丢。

定理 1.4.4：互素正整数的整除性质

◆ p.405

课件提出定理 1.4.4：设 aaa、bbb 是两个互素的正整数，则 （1）若 a∣Da \mid Da∣D、b∣Db \mid Db∣D，则 ab∣Dab \mid Dab∣D。

直觉：DDD 同时含有因数 aaa 和 bbb，而 a,ba, ba,b 没有公共成分，所以 DDD 应该把 a⋅ba \cdot ba⋅b 整个含进去。如果 a,ba, ba,b 不互素这个结论会假：例如 a=b=2a = b = 2a=b=2，D=4D = 4D=4，2∣42 \mid 42∣4 成立但 ab=4∣4ab = 4 \mid 4ab=4∣4 虽然碰巧成立，换 D=4,a=2,b=4D=4, a=2, b=4D=4,a=2,b=4 不互素时 2∣4,4∣42\mid4, 4\mid42∣4,4∣4 而 8∤48 \nmid 48∤4。所以互素条件是本质的。

◆ p.406-409｜定理 1.4.4(1) 的证明：写出商

证明从 b∣Db \mid Db∣D 出发：由整除的定义，存在整数 qqq 使得 D=qbD = qbD=qb。又已知 a∣Da \mid Da∣D，代入 D=qbD = qbD=qb 得 a∣qba \mid qba∣qb。

这一步只是把"DDD 被 bbb 除的商"显式写出来，再把 "a∣Da \mid Da∣D" 改写成 "aaa 整除 qbqbqb"。现在的目标变成：从 a∣qba \mid qba∣qb 与 (a,b)=1(a, b) = 1(a,b)=1 推出 ab∣Dab \mid Dab∣D。注意 D=qbD = qbD=qb，所以 ab∣Dab \mid Dab∣D 等价于 a∣qa \mid qa∣q——即只要证明"aaa 整除商 qqq"，两边再乘 bbb 就得到 ab∣Dab \mid Dab∣D。

◆ p.410-411｜关键一步：互素消去律

由 a∣qba \mid qba∣qb 且 (a,b)=1(a, b) = 1(a,b)=1，用消去律得 a∣qa \mid qa∣q。

消去律的依据是第一章 1.3 节的定理：若 a∣bca \mid bca∣bc 且 (a,b)=1(a, b) = 1(a,b)=1，则 a∣ca \mid ca∣c。它的证明用 Bézout 等式：存在整数 s,ts, ts,t 使 sa+tb=1sa + tb = 1sa+tb=1，两边乘 qqq 得 q=qsa+qtbq = qsa + qtbq=qsa+qtb；由 a∣qba \mid qba∣qb 知 a∣qtba \mid qtba∣qtb，又 a∣qsaa \mid qsaa∣qsa，所以 aaa 整除两者的和 qqq。这一步是整个定理的心脏：把"同时被 a,ba, ba,b 整除"转化为"被乘积整除"，靠的正是互素。

◆ p.412-421｜证明完成与(2)的证明

由 a∣qa \mid qa∣q，存在整数 q′q'q′ 使得 q=q′aq = q'aq=q′a，代回 D=qbD = qbD=qb 得 D=q′abD = q'abD=q′ab，于是 ab∣Dab \mid Dab∣D，(1) 证毕。

接着课件证明（2）：[a,b]=ab[a, b] = ab[a,b]=ab。分两步：

第一步，ababab 显然是 aaa、bbb 的一个公倍数（ab=a⋅bab = a \cdot bab=a⋅b 被 aaa 整除，也被 bbb 整除）。

第二步，根据刚证好的 (1)，aaa、bbb 的任一公倍数 DDD 都可被 ababab 整除，于是对每个公倍数 DDD 有正整数关系 ab≤∣D∣ab \le |D|ab≤∣D∣。也就是说 ababab 不超过任何公倍数的绝对值，而它自己又是正的公倍数，所以 ababab 是最小公倍数，即 [a,b]=ab[a, b] = ab[a,b]=ab。

这个"两步论证"值得记住：先验证候选者是公倍数，再验证它整除一切公倍数（从而最小）。后面推论 1、定理 1.4.5(1) 的证明都是同一套路。

◆ p.422｜引出一般情形

定理 1.4.4 的两条结论旁边，课件画了一个箭头指向 "(a,b)=?(a, b) = ?(a,b)=?"——这是过渡提问：互素时 [a,b]=ab[a, b] = ab[a,b]=ab，那么对一般的正整数 a,ba, ba,b（不互素），[a,b][a, b][a,b] 与 (a,b)(a, b)(a,b) 之间有什么关系？这个问题由后面的定理 1.4.5 回答：[a,b]=ab(a,b)[a, b] = \dfrac{ab}{(a, b)}[a,b]=(a,b)ab​。

◆ p.423-424｜例 4 与例 5

例 4：121212 和 353535 是两个互素的正整数，则 [12,35]=12×35[12, 35] = 12 \times 35[12,35]=12×35。验证互素：12=22⋅312 = 2^2 \cdot 312=22⋅3，35=5⋅735 = 5 \cdot 735=5⋅7，没有公共素因数，(12,35)=1(12, 35) = 1(12,35)=1，直接用定理 1.4.4(2)。

例 5：设 ppp 和 qqq 是两个不同的素数，则 [p,q]=pq[p, q] = pq[p,q]=pq。理由：不同素数 p,qp, qp,q 的公因数只有 111，故 (p,q)=1(p, q) = 1(p,q)=1，仍由定理 1.4.4(2) 得 [p,q]=pq[p, q] = pq[p,q]=pq。这个例子后面在 RSA 与素数分解里会反复出现：不同素数的最小公倍数就是它们的乘积。

◆ p.425-427｜思考（推论 1）及其证明

  1. 设 aaa、bbb、ccc 是三个不全为零的整数，如果 a=qb+ca = qb + ca=qb+c（qqq 是整数），那么 aaa、bbb 的公因数与 (2)（bbb、ccc 的公因数）完全相同。理由：a=qb+ca = qb + ca=qb+c 说明 aaa 与 bbb 的线性组合可用 b,cb, cb,c 表出，反之 c=a−qbc = a - qbc=a−qb，两对数的公因数集合互相决定，这正是辗转相除法（广义欧几里得除法）求最大公因数的原理。

  2. 以下哪些不定方程有整数解（答案：1、3）： （1）2x+3y=912x + 3y = 912x+3y=91：(2,3)=1(2, 3) = 1(2,3)=1 且 1∣911 \mid 911∣91，有解。 （2）40x+26y=9940x + 26y = 9940x+26y=99：(40,26)=2∤99(40, 26) = 2 \nmid 99(40,26)=2∤99（999999 是奇数），无解。 （3）14x+16y=1614x + 16y = 1614x+16y=16：(14,16)=2∣16(14, 16) = 2 \mid 16(14,16)=2∣16，有解（例如 x=0x = 0x=0？16∣1616 \mid 1616∣16 需 16y=1616y = 1616y=16，y=1y = 1y=1，但 14⋅0+16⋅1=1614 \cdot 0 + 16 \cdot 1 = 1614⋅0+16⋅1=16，确实有解）。 （4）6x+9y=86x + 9y = 86x+9y=8：(6,9)=3∤8(6, 9) = 3 \nmid 8(6,9)=3∤8，无解。 判据：ax+by=cax + by = cax+by=c 有整数解当且仅当 (a,b)∣c(a, b) \mid c(a,b)∣c（Bézout 定理的应用）。

设 aaa、bbb、ccc 是三个正整数，(a,c)=1(a, c) = 1(a,c)=1，下列哪些说法错误（答案：1）： （1）如果 b∣acb \mid acb∣ac，则 b∣ab \mid ab∣a 或 b∣cb \mid cb∣c——错误。反例：b=6b = 6b=6，a=2a = 2a=2，c=3c = 3c=3，(a,c)=1(a, c) = 1(a,c)=1，6∣66 \mid 66∣6 但 6∤26 \nmid 26∤2 且 6∤36 \nmid 36∤3。互素消去律的方向是"a∣bca \mid bca∣bc 且 (a,b)=1(a,b)=1(a,b)=1 则 a∣ca \mid ca∣c"，这里把条件用错了对象。 （2）如果 c∣abc \mid abc∣ab，则 c∣bc \mid bc∣b——正确，正是消去律：(a,c)=1(a, c) = 1(a,c)=1 时 c∣abc \mid abc∣ab 可约去 aaa。 （3）若 a∣ba \mid ba∣b、c∣bc \mid bc∣b，则 ac∣bac \mid bac∣b——正确，由 (a,c)=1(a, c) = 1(a,c)=1 与定理 1.4.4(1)（bbb 是 a,ca, ca,c 的公倍数，被乘积整除）。 （4）若 b∣ab \mid ab∣a、b∣cb \mid cb∣c，则 b=1b = 1b=1——正确：bbb 是互素两数的公因数，只能是 111。
