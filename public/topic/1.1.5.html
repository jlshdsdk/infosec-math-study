一般余数与绝对值最小余数

待学习
阅读全文、收藏与记笔记 →本篇已收录课件原页 →

本课讲欧几里得除法的一般余数形式。此前学过的欧几里得除法（定理 1.1.9）只固定了"余数落在 0 到 b−1 之间"这一种约定，本课把它推广为：余数区间可以整体平移到数轴上任意位置。同一个除法因此可以得到许多组不同的商与余数，课件随后逐个讨论了几种最常用的取法——最小非负余数、最小正余数、最大非正余数、最大负余数和绝对值最小余数。这些概念是后续学习同余与剩余系的基础：选择不同的余数区间，本质上就是在同一个剩余类里选不同的"代表元"。

定理 1.1.10（欧几里得除法的一般形式）与例 13

◆ p.122-126｜定理 1.1.10 与例 13

定理 1.1.10（欧几里得除法）说：设 aaa、bbb 是两个整数，其中 b>0b>0b>0，则对任意的整数 ccc，存在唯一的整数 qqq、rrr，使得

a=qb+r,c≤r<b+ca=qb+r,\qquad c\le r<b+ca=qb+r,c≤r<b+c

也就是说，余数不必被限制在 0≤r<b0\le r<b0≤r<b，而是被限制在以 ccc 为左端点、长度为 bbb 的半开区间 [c, b+c)[c,\,b+c)[c,b+c) 内。因为区间长度仍是 bbb（除数），里面恰好装得下 bbb 个整数，所以唯一性依然成立——每个剩余类在这个区间里恰好有一个代表。课件注明"证明可仿照定理 1.1.9，略"。课件外的补充推导：给定 a,b,ca,b,ca,b,c，可以先做普通带余除法 a=b⋅q0+r0a=b\cdot q_0+r_0a=b⋅q0​+r0​（0≤r0<b0\le r_0<b0≤r0​<b），若 r0≥cr_0\ge cr0​≥c 就直接取 q=q0, r=r0q=q_0,\ r=r_0q=q0​, r=r0​；若 r0<cr_0<cr0​<c，则利用 r0≥0>cr_0\ge 0>cr0​≥0>c 时必有 b+r0≥b>cb+r_0\ge b>cb+r0​≥b>c（因为 c≤0c\le 0c≤0，区间整体下移不超过 bbb 格），把商减 1、余数加 bbb，即 q=q0−1, r=r0+bq=q_0-1,\ r=r_0+bq=q0​−1, r=r0​+b，此时 c≤r0+b<b+cc\le r_0+b<b+cc≤r0​+b<b+c 成立。两种情形合并即得存在性；唯一性与定理 1.1.9 的论证完全相同（两个不同的 rrr 之差是 bbb 的倍数但绝对值小于 bbb，只能为 0）。

例 13：取 a=10a=10a=10、b=5b=5b=5，对不同的 ccc 演算（数值已用 python 复算）：

  • 取 c=0c=0c=0 时，区间是 0≤r<50\le r<50≤r<5。由 10=2×5+010=2\times 5+010=2×5+0，可得 q=2q=2q=2、r=0r=0r=0。检查：000 落在 [0,5)[0,5)[0,5) 内，合法。
  • 取 c=2c=2c=2 时，区间是 2≤r<72\le r<72≤r<7。此时余数 000 不合法了，必须把商减小、余数加上一个除数：由 10=1×5+510=1\times 5+510=1×5+5，可得 q=1q=1q=1、r=5r=5r=5。检查：555 落在 [2,7)[2,7)[2,7) 内，合法。
  • 取 c=−6c=-6c=−6 时，区间是 −6≤r<−1-6\le r<-1−6≤r<−1。由 10=3×5+(−5)10=3\times 5+(-5)10=3×5+(−5)，可得 q=3q=3q=3、r=−5r=-5r=−5。检查：−5-5−5 落在 [−6,−1)[-6,-1)[−6,−1) 内，合法。

例 13 说明：a=10a=10a=10 除以 555 本可以写成 10=2×5+010=2\times5+010=2×5+0，但当区间移动后，"余数恰好等于除数"（10=1×5+510=1\times5+510=1×5+5）甚至"商比 a/ba/ba/b 大"（10=3×5+(−5)10=3\times5+(-5)10=3×5+(−5)，因为 rrr 是负数，商必须补回来）都可能是唯一的合法写法。等式 a=qb+ra=qb+ra=qb+r 本身有很多种写法，定理 1.1.10 的贡献是指出：一旦指定区间，qqq 和 rrr 就唯一确定。

拓展（课件外补充）：把例 13 一般化，qqq 有显式公式 q=⌊a−cb⌋q=\left\lfloor\dfrac{a-c}{b}\right\rfloorq=⌊ba−c​⌋，r=a−bqr=a-bqr=a−bq。例如 a=10,b=5,c=2a=10,b=5,c=2a=10,b=5,c=2 时 q=⌊8/5⌋=1q=\lfloor 8/5\rfloor=1q=⌊8/5⌋=1，r=10−5=5r=10-5=5r=10−5=5，与课件一致。这个公式在编程语言里常用于实现"任意偏移的取模"。

移动区间后余数如何变化：以 14 除以 4 为例

◆ p.127-130｜不同的 ccc 对应不同的 rrr

课件提出核心问题（红字）：不同的 ccc 可能对应不同的 rrr，哪个 ccc 能使得 rrr 为最小非负余数？接着以 a=14a=14a=14、b=4b=4b=4 为例，把一串 ccc 的取值逐个算出（数值已复算）：

  • 取 c=−5c=-5c=−5 时，区间为 [−5,−1)[-5,-1)[−5,−1)，由 14=4×4+(−2)14=4\times 4+(-2)14=4×4+(−2)，可得 r=−2r=-2r=−2（−2-2−2 在 [−5,−1)[-5,-1)[−5,−1) 内，合法）；
  • 取 c=−4c=-4c=−4 时，区间为 [−4,0)[-4,0)[−4,0)，由 14=4×4+(−2)14=4\times 4+(-2)14=4×4+(−2)，可得 r=−2r=-2r=−2；
  • 取 c=−3c=-3c=−3 时，区间为 [−3,1)[-3,1)[−3,1)，由 14=4×4+(−2)14=4\times 4+(-2)14=4×4+(−2)，可得 r=−2r=-2r=−2；
  • 取 c=−2c=-2c=−2 时，区间为 [−2,2)[-2,2)[−2,2)，由 14=4×4+(−2)14=4\times 4+(-2)14=4×4+(−2)，可得 r=−2r=-2r=−2；
  • 取 c=0c=0c=0 时，区间为 [0,4)[0,4)[0,4)，由 14=3×4+214=3\times 4+214=3×4+2，可得 r=2r=2r=2；
  • 取 c=1c=1c=1 时，区间为 [1,5)[1,5)[1,5)，由 14=3×4+214=3\times 4+214=3×4+2，可得 r=2r=2r=2；
  • 取 c=2c=2c=2 时，区间为 [2,6)[2,6)[2,6)，由 14=3×4+214=3\times 4+214=3×4+2，可得 r=2r=2r=2；
  • 取 c=3c=3c=3 时，区间为 [3,7)[3,7)[3,7)，此时 r=2r=2r=2 不再合法（2<32<32<3），必须改写为 14=2×4+614=2\times 4+614=2×4+6，可得 r=6r=6r=6。

可以观察到规律：只要 −2-2−2 和 222 同落在区间 [c,b+c)[c,b+c)[c,b+c) 内，两种写法给出的"余数"都合法，而定理保证区间内代表唯一，所以这批 ccc 对应的 rrr 相同。ccc 从 −2-2−2 增大到 222 时 r=−2r=-2r=−2 与 r=2r=2r=2 分居区间两端的情形交错出现；到 c=3c=3c=3 时区间整体跑到 222 的右边，只能换用 r=6r=6r=6。p.128-130 三页是同一张幻灯片的逐步动画：先完整列出八行算式，再框出 c=0,1,2c=0,1,2c=0,1,2 三行（它们的余数都是 222），最后高亮 c=0c=0c=0 那一行——它正是最小非负余数。

拓展（课件外补充）：用 python 可以直接验证哪些 ccc 给出 r=2r=2r=2：对 c∈{−2,−1,0,1,2}c\in\{-2,-1,0,1,2\}c∈{−2,−1,0,1,2}，区间 [c,c+4)[c,c+4)[c,c+4) 都包含 222，故 r=2r=2r=2；c≤−3c\le-3c≤−3 时 r=−2r=-2r=−2；c≥3c\ge 3c≥3 时 r=6r=6r=6。老讲解中"c=−5,−4,−3,−2c=-5,-4,-3,-2c=−5,−4,−3,−2 时都取 q=4,r=−2q=4,r=-2q=4,r=−2；c=0,1,2c=0,1,2c=0,1,2 时 q=3,r=2q=3,r=2q=3,r=2；c=3c=3c=3 时 q=2,r=6q=2,r=6q=2,r=6"与此一致。

数轴图示：ccc 的取值决定余数的名称

◆ p.131-139｜当 c=0c=0c=0：最小非负余数

从这一页起，课件改用数轴图来回答"哪个 ccc 使 rrr 具有特殊地位"。数轴上标出三个点：左端点 ccc（实心，可取到）、红色的余数 rrr、右端点 b+cb+cb+c（空心，取不到）。当 c=0c=0c=0 时，区间就是 0≤r<b0\le r<b0≤r<b：rrr 被"卡"在 0 和 bbb 之间，只能是全体非负整数中最小的那个代表，所以这时的 rrr 叫做最小非负余数。这就是我们最熟悉的普通带余除法 a mod ba\bmod bamodb 的余数。p.135-139 是同一内容的重复强调（数轴图先以 c,r,b+cc,r,b+cc,r,b+c 出现，再代回 c=0c=0c=0 变成 0,r,b0,r,b0,r,b，最后标出"最小非负余数"五个字），属于同一张幻灯片的动画帧，无新内容。

拓展（课件外补充）：为什么 c=0c=0c=0 给出的恰好是"最小"非负代表？因为区间 [0,b)[0,b)[0,b) 装下了全部 bbb 个剩余类的代表，且每个剩余类的所有整数形如 r+kbr+kbr+kb（k∈Zk\in\mathbb Zk∈Z），其中落在 [0,b)[0,b)[0,b) 的那个正是最小的非负者。这也是编程语言 % 运算符的数学来源。

当 c=1c=1c=1：最小正余数

◆ p.140-142｜当 c=1c=1c=1：最小正余数

数轴图换成 c=1c=1c=1：区间是 1≤r<b+11\le r<b+11≤r<b+1，左端点从 0 挪到 1。这样余数永远不取 0，最小的可能取值是 1，所以这时的 rrr 叫做最小正余数。p.140 是先出现 c,r,b+cc,r,b+cc,r,b+c 的空标架，p.141-142 代入 c=1c=1c=1 得 1,r,b+11,r,b+11,r,b+1 并标出"最小正余数"，是同一张幻灯片的动画过程。

拓展（课件外补充）：最小正余数有个容易被忽视的性质——当 b∣ab\mid ab∣a（即被整除）时，最小非负余数是 000，但最小正余数却是 bbb 本身。例如 15=2×5+515=2\times 5+515=2×5+5，"最小正余数"是 555 而不是 000。这就是说"整除时余数为零"的说法只对 c=0c=0c=0 的约定成立。

当 c=−b+1c=-b+1c=−b+1：最大非正余数

◆ p.143-146｜当 c=−b+1c=-b+1c=−b+1：最大非正余数

把区间移到 0 的左侧：取 c=−b+1c=-b+1c=−b+1，区间为 −b+1≤r<1-b+1\le r<1−b+1≤r<1，即 −b<r≤0-b<r\le 0−b<r≤0（因为 rrr 是整数，r<1r<1r<1 等价于 r≤0r\le 0r≤0）。此时余数最大的可能取值是 0，再往上就出区间了，所以这时的 rrr 叫做最大非正余数。数轴图上左端点标 −b+1-b+1−b+1（实心），右端点标 111，随后动画显示 000 落在区间内部、r≤0r\le 0r≤0，并标出"最大非正余数"。p.144-146 为同一幻灯片的逐步动画帧。

当 c=−bc=-bc=−b：最大负余数

◆ p.147-149｜当 c=−bc=-bc=−b：最大负余数

再往左挪一格：取 c=−bc=-bc=−b，区间为 −b≤r<0-b\le r<0−b≤r<0。此时余数严格小于 0，且 −b-b−b 是能取到的最小值（它等于负的除数），余数在"不越过 −b-b−b"的前提下取到最大的负值，故称最大负余数。注意这个约定下余数永远不为 0：即使 b∣ab\mid ab∣a，也要写成 a=(q+1)×b+(−b)a=(q+1)\times b+(-b)a=(q+1)×b+(−b) 的形式。p.147-149 同样是数轴图从 c,r,b+cc,r,b+cc,r,b+c 逐步代换成 −b,r,0-b,r,0−b,r,0 的动画帧。

拓展（课件外补充）：把 c=0,1,−b+1,−bc=0,1,-b+1,-bc=0,1,−b+1,−b 四种约定并排看，会发现它们是同一对区间的两种"端点分配"：[0,b)[0,b)[0,b) 与 [−b,0)[-b,0)[−b,0)、[1,b+1][1,b+1][1,b+1] 与 [−b+1,1][-b+1,1][−b+1,1] 互为镜像。前两种偏爱正的代表，后两种偏爱负的代表。

若 b=2kb=2kb=2k（偶数除数）：绝对值最小余数的两种取法

◆ p.150-151｜偶数除数，c=−kc=-kc=−k 的情形

前面四种区间的长度都是 bbb，但代表离 0 有远有近。想让余数的绝对值尽量小，就应该把区间对称地放在 0 的两侧。先设 b=2kb=2kb=2k（bbb 为偶数）：取 c=−kc=-kc=−k 时，区间为 −k≤r<k-k\le r<k−k≤r<k，数轴上即 −b2≤r<b2-\dfrac{b}{2}\le r<\dfrac{b}{2}−2b​≤r<2b​，课件标出这时的 rrr 叫做绝对值最小余数。区间除左端点外关于 0 对称，任何余数的绝对值都不超过 k=b/2k=b/2k=b/2。

◆ p.152-155｜偶数除数，c=−k+1c=-k+1c=−k+1 的情形

若改取 c=−k+1c=-k+1c=−k+1，区间为 −k+1≤r<k+1-k+1\le r<k+1−k+1≤r<k+1，数轴图上左端点 −k+1-k+1−k+1、右端点 k+1k+1k+1（空心），余数 rrr 夹在中间；因为 rrr 是整数，这等价于 −k<r≤k-k<r\le k−k<r≤k，即 −b2<r≤b2-\dfrac{b}{2}<r\le\dfrac{b}{2}−2b​<r≤2b​，同样给出绝对值最小余数。p.154-155 的动画帧把 −k-k−k 点也画出来（空心）以示对比：−k-k−k 本身取不到，但 kkk 取得到。

◆ p.156-157｜两种取法都可以

p.156-157 用数轴图把两种取法并列：−b2≤r<b2-\dfrac{b}{2}\le r<\dfrac{b}{2}−2b​≤r<2b​（c=−kc=-kc=−k）与 −b2<r≤b2-\dfrac{b}{2}<r\le\dfrac{b}{2}−2b​<r≤2b​（c=−k+1c=-k+1c=−k+1），都标注"绝对值最小余数"。这正是定义页（p.164-167）中"两种情况都可以"批注的来源：偶数除数时，±b/2\pm b/2±b/2 两点到 0 等距，区间必须二选一地把这个"最远点"划进来——要么左闭右开、要么左开右闭——选定一种并全程一致使用，唯一性才不被破坏。

若 b=2k+1b=2k+1b=2k+1（奇数除数）：绝对值最小余数唯一

◆ p.158-163｜奇数除数，c=−kc=-kc=−k 的情形

设 b=2k+1b=2k+1b=2k+1（bbb 为奇数）：取 c=−kc=-kc=−k 时，区间为 −k≤r<k+1-k\le r<k+1−k≤r<k+1。数轴图先标出 −k, r, k, k+1-k,\ r,\ k,\ k+1−k, r, k, k+1 四个点，再画出 −b2=−k−12-\dfrac{b}{2}=-k-\dfrac12−2b​=−k−21​ 与 b2=k+12\dfrac{b}{2}=k+\dfrac122b​=k+21​ 两个半整数端点，说明区间恰好是 −b2≤r<b2-\dfrac{b}{2}\le r<\dfrac{b}{2}−2b​≤r<2b​。与偶数情形不同，区间两端 −k-k−k 与 kkk 到 0 的距离不相等（k<k+1k<k+1k<k+1），不存在"两个等距端点抢位置"的问题，所以奇数除数的绝对值最小余数不需要额外约定、天然唯一：它就是绝对值不超过 b2\dfrac{b}{2}2b​ 的那个唯一整数代表。p.158-163 为同一幻灯片逐步加注"绝对值最小余数"的动画帧。

拓展（课件外补充）：用 python 体会奇偶之别——15 除以 4（除数为偶）：15=4×4+(−1)15=4\times4+(-1)15=4×4+(−1)，∣−1∣=1|{-1}|=1∣−1∣=1 是绝对值最小余数，区间 [−2,2)[-2,2)[−2,2) 与 (−2,2](-2,2](−2,2] 都合法；17 除以 4（除数为奇）：17=4×4+117=4\times4+117=4×4+1，绝对值最小余数只能是 111，因为 −2-2−2 与 222 都到不了（∣r∣≤1.5|r|\le 1.5∣r∣≤1.5 只容得下 ±1,0\pm1,0±1,0，其中模 4 同余于 17 的只有 1）。

定义：五种常用余数小结

◆ p.164-167｜定义：常用形式的欧几里得除法及余数

课件用一整页把前面的讨论收拢成定义。常用形式的欧几里得除法及余数有：

  1. 当 c=0c=0c=0 时，有 0≤r<b0\le r<b0≤r<b，这时 rrr 叫做最小非负余数。
  2. 当 c=1c=1c=1 时，有 1≤r<b+11\le r<b+11≤r<b+1，这时 rrr 叫做最小正余数。
  3. 当 c=−b+1c=-b+1c=−b+1 时，有 −b+1≤r<1-b+1\le r<1−b+1≤r<1，这时 rrr 叫做最大非正余数。
  4. 当 c=−bc=-bc=−b 时，有 −b≤r<0-b\le r<0−b≤r<0，这时 rrr 叫做最大负余数。
  5. 若 b=2kb=2kb=2k（bbb 为偶数）：当 c=−kc=-kc=−k 时，有 −k≤r<k-k\le r<k−k≤r<k，即 −b2≤r<b2-\dfrac{b}{2}\le r<\dfrac{b}{2}−2b​≤r<2b​；当 c=−k+1c=-k+1c=−k+1 时，有 −k<r≤k-k<r\le k−k<r≤k，即 −b2<r≤b2-\dfrac{b}{2}<r\le\dfrac{b}{2}−2b​<r≤2b​。两种情况都可以。 若 b=2k+1b=2k+1b=2k+1（bbb 为奇数）：当 c=−kc=-kc=−k 时，有 −k≤r<k+1-k\le r<k+1−k≤r<k+1，即 −b2<r<b2-\dfrac{b}{2}<r<\dfrac{b}{2}−2b​<r<2b​。这时 rrr 叫做绝对值最小余数。

p.165-167 是同一页的三帧动画：p.165 用括线把第 5 条中奇偶两种绝对值区间接起来，强调无论奇偶都满足统一形式 ∣−b2∣≤∣r∣≤∣b2∣\left|-\dfrac{b}{2}\right|\le|r|\le\left|\dfrac{b}{2}\right|​−2b​​≤∣r∣≤​2b​​（即余数被限制在以 0 为中心、半径 b/2b/2b/2 的范围内）；p.166-167 在偶数除数的两种区间旁加注"两种情况都可以"。注意奇数情形的区间 −k≤r<k+1-k\le r<k+1−k≤r<k+1 化为 −b2<r<b2-\dfrac{b}{2}<r<\dfrac{b}{2}−2b​<r<2b​ 时，左端其实是闭的（−k=−b−12>−b2-k=-\frac{b-1}{2}>-\frac b2−k=−2b−1​>−2b​），两个半整数端点都取不到，故绝对值最小余数唯一。

拓展（课件外补充）：这五种约定的共同骨架是"长度为 bbb 的半开区间内每个剩余类恰有一个代表"。考试中最常出错的是第 2、4 条的边界：最小正余数的范围包含 bbb（1≤r≤b1\le r\le b1≤r≤b），最大负余数的范围包含 −b-b−b（−b≤r≤−1-b\le r\le -1−b≤r≤−1）——区间端点写法虽是 1≤r<b+11\le r<b+11≤r<b+1 与 −b≤r<0-b\le r<0−b≤r<0，但对整数而言等价于把 ±b\pm b±b 含在内。
