## 讲解与来源

`content/guides-*.md` 是辅助理解的讲解，使用标准 LaTeX 表达式；原始概念、定理、证明、例题与练习以网站保留的课件原页为依据。原页索引与搜索使用 OCR 辅助定位，识别文字可能含错字、错误标点或公式符号，不作为替代原页的权威转录。

已收录的 9,024 帧的主题归属及连续页码见 `public/data/coverage.json`。来源图像与图像去重不合并课件页码，也不删除动画步骤。原页浏览器支持在知识点对应的所有来源区间内逐页查看。

每篇正文穿插可追溯到课件索引的代表性原图。点击图片可放大，点击图下的链接可查看已收录的前后原页；也可打开该知识点关联的已收录原页。大图和相邻页面按需加载，全文搜索在后台处理以保持阅读流畅。正式二级目录保留课件章首页的编号和标题。三级知识点有课件原编号时沿用原编号；原课件未标三级数字编号的内容由网站按课件顺序增加整理编号，并清楚标注“整理”。一个原子目涉及多篇讲解时可聚合阅读；一篇讲解跨子目时定位到对应段落，完整文章仍可打开。导学单独提供入口，不占正式二级目录。

「课件与讲解对照」按原页中的标签列出实际讲解位置、重复动画、识别误差及原资料缺失。可按章节、类型和关键词筛选，并直接跳转到讲解小节或来源页。对应记录保存在 `content/coverage-*.json`，公开数据为 `public/data/coverage-audit.json`。对应清单只核查当前已收录原页中的可识别条目，不表示雨课堂资料已收齐，也不等同于每一题都已独立数值验算。

课件保留原作者信息，相关课程材料权利归原作者；网站中的补充讲解不表示课程教师的官方答案。

## 维护内容

本机 `.work/` 保存来源索引和识别中间结果，不上传到仓库。更新讲解后，用 `tools/build_data.py` 重新生成网站数据；缺少任何主题讲解时，正式构建会失败。`--draft` 仅用于本地开发。提交到 main 后，GitHub Actions 会先运行检查，再发布 `public/`。

更新对应记录后运行 `tools/build_coverage.py`。它检查全部原页索引是否有记录、来源区间与讲解小节是否真实存在；存在已确认而待补的讲解时禁止作为完成版发布。发布时通过 `--check` 再核对公开数据与记录一致。

更新讲解及对照记录后，还需运行 `tools/build_inline_slides.py` 更新正文配图索引。`public/ppt-outline.js` 管理课件正式目录、资料状态及讲解段落映射；`public/course-map.js` 保留内部学习路径与前置知识。正式目录、内部学习路径、旧文章入口与配图来源分别有自动检查。参考站的阅读背景和 Noto Serif SC 字体随站点提供，字体许可见 `public/assets/NotoSerifSC-OFL.txt`。
