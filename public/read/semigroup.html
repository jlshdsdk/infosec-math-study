第8章 / 8.1 群 / 8.1.2 半群与群

半群与含幺半群

图文讲解已收录课件原页原页索引
本篇内容
定义 6.2.1 与例 1、例 2例 3：常见数集在四则运算下是否为半群

本主题开始进入代数系统的第一个具体结构。上一节定义了二元运算与代数系统，本节（对应信安教材定义 8.1.2）在最一般的层面给运算加上第一个条件——结合律，得到半群的概念；半群是群的前置：群还要再要求单位元与逆元。课件通过定义 6.2.1 给出半群定义，并用例 1、例 2、例 3 展示判断一个代数系统是否为半群的标准流程。同一份课件在三次授课记录（10 月 19 日授课第 547-553 页、第八章原版第 100-106 页、10 月 26 日授课第 100-106 页）中重复出现，内容一致，下面合并按页块讲解。

定义 6.2.1 与例 1、例 2

◆ p.547-549｜定义 6.2.1、例 1、例 2（同见 p.100-102）

定义 6.2.1：设 SSS 是一个非空集合，若 ⋅\cdot⋅ 为 SSS 上的二元代数运算，且满足结合律，则称该代数系统 (S,⋅)(S, \cdot)(S,⋅) 为半群。

拆开看，判定半群需要三个条件同时成立：集合非空；运算封闭（"二元代数运算"本身就要求任意 a,b∈Sa, b \in Sa,b∈S 都有 a⋅b∈Sa \cdot b \in Sa⋅b∈S）；结合律 (a⋅b)⋅c=a⋅(b⋅c)(a \cdot b) \cdot c = a \cdot (b \cdot c)(a⋅b)⋅c=a⋅(b⋅c) 对任意三个元素成立。半群不要求交换律、不要求单位元、更不要求逆元。注意课件标题写"定义 6.2.1"，而页眉注明对应信安教材中的定义 8.1.2，编号不同是教材与课件编号体系差异所致。

例 1：设 SSS 是一个非空集合，ρ(S)\rho(S)ρ(S) 是 SSS 的幂集，∩\cap∩ 和 ∪\cup∪ 是 ρ(S)\rho(S)ρ(S) 上的交运算和并运算，则 (ρ(S),∩)(\rho(S), \cap)(ρ(S),∩) 为半群，(ρ(S),∪)(\rho(S), \cup)(ρ(S),∪) 为半群。

判定过程：ρ(S)\rho(S)ρ(S) 是 SSS 的全部子集组成的集合，至少包含空集 ∅\varnothing∅，故非空。任取 A,B⊆SA, B \subseteq SA,B⊆S，A∩BA \cap BA∩B 与 A∪BA \cup BA∪B 仍是 SSS 的子集，故交、并都是 ρ(S)\rho(S)ρ(S) 上的二元代数运算（封闭）。集合的交与并满足结合律：(A∩B)∩C=A∩(B∩C)(A \cap B) \cap C = A \cap (B \cap C)(A∩B)∩C=A∩(B∩C)，(A∪B)∪C=A∪(B∪C)(A \cup B) \cup C = A \cup (B \cup C)(A∪B)∪C=A∪(B∪C)，这是集合运算的基本定律。三个条件齐备，两个系统都是半群。

例 2：设 SSS 是一个非空集合，规定 SSS 上的运算 ⊕\oplus⊕ 如下：a⊕b=ba \oplus b = ba⊕b=b，其中 aaa、bbb 是 SSS 中任意元素。

判定过程：对任意 a,b∈Sa, b \in Sa,b∈S，a⊕b=b∈Sa \oplus b = b \in Sa⊕b=b∈S，显然 ⊕\oplus⊕ 为 SSS 上的二元代数运算。对 SSS 中任意三个元素 aaa、bbb、ccc：(a⊕b)⊕c=b⊕c=c(a \oplus b) \oplus c = b \oplus c = c(a⊕b)⊕c=b⊕c=c（内层 a⊕ba \oplus ba⊕b 等于第二操作数 bbb，再与 ccc 运算又取 ccc）；a⊕(b⊕c)=a⊕c=ca \oplus (b \oplus c) = a \oplus c = ca⊕(b⊕c)=a⊕c=c（内层 b⊕cb \oplus cb⊕c 等于 ccc，外层取第二操作数还是 ccc）。故 (a⊕b)⊕c=a⊕(b⊕c)(a \oplus b) \oplus c = a \oplus (b \oplus c)(a⊕b)⊕c=a⊕(b⊕c)，⊕\oplus⊕ 满足结合律，因此 (S,⊕)(S, \oplus)(S,⊕) 为半群。

这个例子的运算规则是"结果永远等于右边的操作数"。它能结合的深层原因在于两边最终都归结为最右边的 ccc。

拓展（课件外补充）：例 2 的半群还有两个有趣的性质。若 SSS 至少有两个元素，它不交换：a⊕b=ba \oplus b = ba⊕b=b 而 b⊕a=ab \oplus a = ab⊕a=a，两者可以不同。它也没有双侧单位元：任何 uuu 都满足 u⊕a=au \oplus a = au⊕a=a（每个元素都是"左单位元"），但 a⊕u=u≠aa \oplus u = u \ne aa⊕u=u=a（当 u≠au \ne au=a 时），所以找不到两侧都充当单位的元素。这说明"存在大量左单位元"并不保证存在双侧单位元，单位元的左右定义在非交换系统中是实质区别。

例 3：常见数集在四则运算下是否为半群

◆ p.550-552｜例 3 的 (1)(2) 两条（同见 p.103-105）

例 3：对于自然数集 N\mathbb{N}N、整数集 Z\mathbb{Z}Z、有理数集 Q\mathbb{Q}Q、实数集 R\mathbb{R}R、正整数集 Z+\mathbb{Z}^+Z+，以及数的加法 +++、减法 −-−、乘法 ×\times×：

(1) 代数系统 (Z,−)(\mathbb{Z}, -)(Z,−)、(Q,−)(\mathbb{Q}, -)(Q,−)、(R,−)(\mathbb{R}, -)(R,−) 不是半群。因为数的减法运算不满足结合律。

具体看：(3−2)−1=1−1=0(3 - 2) - 1 = 1 - 1 = 0(3−2)−1=1−1=0，而 3−(2−1)=3−1=23 - (2 - 1) = 3 - 1 = 23−(2−1)=3−1=2，两者不相等，结合律在 Z\mathbb{Z}Z 中就已失效，Q\mathbb{Q}Q、R\mathbb{R}R 中同样如此（例如 (5−3)−2=0≠4=5−(3−2)(5-3)-2 = 0 \ne 4 = 5-(3-2)(5−3)−2=0=4=5−(3−2)）。注意减法在 Z\mathbb{Z}Z、Q\mathbb{Q}Q、R\mathbb{R}R 上是封闭的二元运算，败在结合律这一关；而 N\mathbb{N}N、Z+\mathbb{Z}^+Z+ 上的减法更早就败在封闭性上（1−2∉N1 - 2 \notin \mathbb{N}1−2∈/N），连二元运算都算不上，自然不是半群。

(2) 代数系统 (Z+,+)(\mathbb{Z}^+, +)(Z+,+) 是半群。正整数加正整数仍是正整数（封闭），加法满足结合律，故为半群。但要注意它没有单位元：0∉Z+0 \notin \mathbb{Z}^+0∈/Z+，任何正整数 aaa 加上哪个正整数都不会回到 aaa 自己。这说明半群可以没有单位元——这正是半群与后面"含幺半群"的分界线。

◆ p.553｜例 3 的 (3) 条（同见 p.106）

(3) 代数系统 (N,+)(\mathbb{N}, +)(N,+)、(N,×)(\mathbb{N}, \times)(N,×)、(Z,+)(\mathbb{Z}, +)(Z,+)、(Z,×)(\mathbb{Z}, \times)(Z,×)、(Q,+)(\mathbb{Q}, +)(Q,+)、(Q,×)(\mathbb{Q}, \times)(Q,×)、(R,+)(\mathbb{R}, +)(R,+)、(R,×)(\mathbb{R}, \times)(R,×)、(Z+,×)(\mathbb{Z}^+, \times)(Z+,×) 都是半群。

理由是统一的：这些数集在相应运算下都封闭（加法、乘法在自然数、整数、有理数、实数、正整数中均不出界），而加法与乘法的结合律是数系的基本定律。逐个核对封闭性：N\mathbb{N}N 与 Z+\mathbb{Z}^+Z+ 对加、乘封闭；Z\mathbb{Z}Z、Q\mathbb{Q}Q、R\mathbb{R}R 对加、乘封闭。其中 Q\mathbb{Q}Q、R\mathbb{R}R 排除了除法，因为除法对 0 不封闭（除数不能为 0），课件没有把除法列入。

拓展（课件外补充）：把例 3 与后续内容连起来看，可以排成一条结构升级的链：(Z+,+)(\mathbb{Z}^+, +)(Z+,+) 是半群但无单位元；(N,+)(\mathbb{N}, +)(N,+) 有单位元 0，是含幺半群，但除 0 外无人可逆，不是群；(Z,+)(\mathbb{Z}, +)(Z,+)、(Q,+)(\mathbb{Q}, +)(Q,+)、(R,+)(\mathbb{R}, +)(R,+) 都是群。乘法方面 (Z,×)(\mathbb{Z}, \times)(Z,×) 是含幺半群（单位元 1）而非群，因为 2 的逆 12∉Z\frac{1}{2} \notin \mathbb{Z}21​∈/Z；(Q,×)(\mathbb{Q}, \times)(Q,×) 也不是群（0 无逆元），但 (Q∖{0},×)(\mathbb{Q} \setminus \{0\}, \times)(Q∖{0},×) 是群。判定半群的流程可以总结为逐层筛选：先问非空与封闭，再问结合律，然后才轮到单位元与逆元；每层都要指明集合与运算，不能笼统地说"整数是群"。
