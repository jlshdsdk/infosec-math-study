# 信息安全数学基础 · 期末自学

按雨课堂中已收集的 17 份课件制作的个人自学网站。内容按 **章 → 节 → 知识点** 组织，提供零基础伴读、标准 LaTeX 数学排版、完整课件原页、原页检索、学习笔记、收藏、完成进度与进度导入导出。

在线学习：<https://jlshdsdk.github.io/infosec-math-study/>。手机、平板或电脑打开同一网址即可学习，无需登录。

## 内容范围

- 共 9,024 个课件页面，包含动画逐步展示的页面；完全相同的图像复用同一资源，来源页码保留。
- 共 91 个学习主题。按页面的实际标题归类，跨章课件同时关联到对应章节。
- 覆盖第一章整数的可除性、第二章同余、第三章同余式、第四章二次同余式与平方剩余，以及第八章现有的群论内容。
- 未找到独立标注第五、六、七章的课件。第八章虽以“群、环、域”为文件标题，现有材料主要覆盖群、置换、子群、循环群、陪集、正规子群和 Lagrange 定理，未补造环、域的课程内容。
- 第三章第 3 节沿用之前从课件网页导出的 190 页 PDF 重新渲染，字体与动画效果可能与雨课堂网页略有不同。

## 讲解与来源

`content/guides-*.md` 是辅助理解的讲解，使用标准 LaTeX 表达式；原始概念、定理、证明、例题与练习以网站保留的课件原页为依据。原页索引与搜索使用 OCR 辅助定位，识别文字可能含错字、错误标点或公式符号，不作为替代原页的权威转录。

全部课件页面的主题归属及连续页码见 `public/data/coverage.json`。来源图像与图像去重不合并课件页码，也不删除动画步骤。原页浏览器支持在知识点对应的所有来源区间内逐页查看。

「课件与讲解对照」按原页中的标签列出实际讲解位置、重复动画、识别误差及原资料缺失。可按章节、类型和关键词筛选，并直接跳转到讲解小节或来源页。对应记录保存在 `content/coverage-*.json`，公开数据为 `public/data/coverage-audit.json`。对应清单核查条目是否有讲解，不把它等同于每一题都已独立数值验算。

课件保留原作者信息，相关课程材料权利归原作者；网站中的补充讲解不表示课程教师的官方答案。

## 学习进度与跨设备

网址可直接访问，无需账号。完成状态、笔记、收藏保存在当前浏览器。换设备时，在旧设备导出进度 JSON，在新设备打开网站并导入。导出文件包含个人学习笔记，请自行保存；GitHub Pages 不提供自动跨设备同步。

## 运行与验证

```text
npm ci
npm test
npm run serve
```

本机预览为 `http://127.0.0.1:4173`。网页使用相对路径，可直接发布为 GitHub Pages 项目网站。KaTeX、Markdown 渲染器和字体随网站提供，不依赖外部 CDN。

数学工具使用整数运算，包含扩展欧几里得、一次同余式、CRT、模重复平方、Jacobi 符号与小模平方根枚举。测试通过直接枚举、直接乘法与课件数值交叉核验这些结果，并校验全部原页覆盖、来源区间和 LaTeX 可解析性。

## 维护内容

本机 `.work/` 保存来源索引和识别中间结果，不上传到仓库。更新讲解后，用 `tools/build_data.py` 重新生成网站数据；缺少任何主题讲解时，正式构建会失败。`--draft` 仅用于本地开发。提交到 main 后，GitHub Actions 会先运行检查，再发布 `public/`。

更新对应记录后运行 `tools/build_coverage.py`。它检查全部原页索引是否有记录、来源区间与讲解小节是否真实存在；存在已确认而待补的讲解时禁止作为完成版发布。发布时通过 `--check` 再核对公开数据与记录一致。
