整除的定义、因数与整除性质

待学习
阅读全文、收藏与记笔记 →本篇已收录课件原页 →

本课是全课程的起点，讲整除的定义和由它直接导出的基本性质：因数与倍数的概念、零与正负一号的整除规则，以及传递性、加减保持、线性组合保持三条核心定理。它属于第一章 1.1 节，为后面的欧几里得除法（带余除法）、最大公因数与最小公倍数提供最基本的语言；本章后面证 Bézout 定理、判断不定方程可解性时，用的都是这里的"把整除翻译成含整数系数的等式"这套手法。

整除的定义（定义 1.1.1）

◆ p.10｜1.1 节目录

本页是 1.1 节的目录页，列出本节五个小节：1.1.1 整除基本概念及性质、1.1.2 素数的求法（Eratosthenes 筛法）、1.1.3 欧几里得除法——最小非负余数、1.1.4 素数的平凡判别、1.1.5 欧几里得除法——一般余数。本课只覆盖 1.1.1。

◆ p.11-19｜定义 1.1.1

定义 1.1.1：设 aaa、bbb 是任意两个整数，其中 b≠0b \ne 0b=0。如果存在一个整数 qqq 使得等式

a=qba = qba=qb

成立，则称 bbb 整除 aaa 或者 aaa 被 bbb 整除，记作 b∣ab \mid ab∣a，并把 bbb 叫做 aaa 的因数，把 aaa 叫做 bbb 的倍数。此时 qqq 可写成 a/ba/ba/b 或 ab\dfrac{a}{b}ba​。否则，就称 bbb 不能整除 aaa，或者 aaa 不能被 bbb 整除，记作 b∤ab \nmid ab∤a。

三个必须咬住的细节：

第一，定义只要求 b≠0b \ne 0b=0，aaa 可以是任何整数（包括 000 和负数）。b∣ab \mid ab∣a 里箭头的方向是"除数指向被除数"，读作"b 整除 a"，不要写反。

第二，qqq 必须是整数，这是整除与普通除法的全部区别：5∣505 \mid 505∣50 是因为 50=10×550 = 10 \times 550=10×5 且 10∈Z10 \in \mathbb{Z}10∈Z；3∤53 \nmid 53∤5 是因为 5/35/35/3 不是整数，而不是因为"除不尽"这种模糊说法。

第三，课件特别规定：0∣00 \mid 00∣0。这看起来违反直觉（000 不能当除数），但按定义的字面：存在整数 qqq 使 0=q⋅00 = q \cdot 00=q⋅0（任何 qqq 都行），所以"存在性"满足。课件干脆把它定为约定。注意这只是"0 整除 0"这一对成立；0∣a0 \mid a0∣a 对一切 a≠0a \ne 0a=0 仍然不成立（不存在 qqq 使 a=q⋅0a = q \cdot 0a=q⋅0）。同时，普通分数记号 a/ba/ba/b 仍然只在 b≠0b \ne 0b=0 时有意义，0∣00 \mid 00∣0 的约定不意味着可以计算 0/00/00/0。

◆ p.20｜单选题

题目：以下说法哪个正确？A. 0 整除 0；B. 0 不整除 0。

答案：A。按课件对定义 1.1.1 的特别规定，0∣00 \mid 00∣0 成立。理由：存在整数 qqq（比如 q=1q = 1q=1）使 0=1×00 = 1 \times 00=1×0，满足定义的存在性要求。此题考的就是上一页那条"特别地，规定 0∣00\mid 00∣0"的约定——不要用"0 不能做除数"的小学直觉去否定它，那条直觉限制的是除法运算 a/ba/ba/b，而整除 b∣ab \mid ab∣a 只是一个存在性命题。

◆ p.21｜问题：是否 0 整除 0？

课件把同样的讨论再放一遍：完整定义之后专门提出"问题：是否 0 整除 0？"结论与 p.20 一致：约定 0∣00 \mid 00∣0 成立。要把两件事分开记：整除关系 0∣00 \mid 00∣0 成立（约定）；除式 0/00/00/0 无意义（不允许）。

因数的枚举与基本注记

◆ p.22-25｜例 1：求 50 的所有因数

题目：求 50 的所有因数。

解：按定义，bbb 是 50 的因数当且仅当存在整数 qqq 使 50=qb50 = qb50=qb。逐一试验正因数：50=1×50=2×25=5×1050 = 1 \times 50 = 2 \times 25 = 5 \times 1050=1×50=2×25=5×10，再无其他分解（50=2×5250 = 2 \times 5^250=2×52，因数只能由 222 的幂 1,21, 21,2 与 555 的幂 1,5,251, 5, 251,5,25 组合出 1,2,5,10,25,501, 2, 5, 10, 25, 501,2,5,10,25,50）。由于定义允许 bbb 取负值，每个正因数的相反数也是因数。所以 50 的所有因数为

±1, ±2, ±5, ±10, ±25, ±50\pm 1,\ \pm 2,\ \pm 5,\ \pm 10,\ \pm 25,\ \pm 50±1, ±2, ±5, ±10, ±25, ±50

共 12 个。课件分四步逐步展示：先写正因数 1,2,5,10,25,501, 2, 5, 10, 25, 501,2,5,10,25,50，再补上 −1,−2,−5,−10,−25,−50-1, -2, -5, -10, -25, -50−1,−2,−5,−10,−25,−50。

◆ p.26-29｜注(1)：取相反数遍历因数

注 (1)：当 bbb 遍历整数 aaa 的所有因数时，−b-b−b 也遍历整数 aaa 的所有因数。

理由：若 b∣ab \mid ab∣a，即 a=qba = qba=qb，则 a=(−q)(−b)a = (-q)(-b)a=(−q)(−b)，而 −q-q−q 仍是整数，所以 −b∣a-b \mid a−b∣a；映射 b↦−bb \mapsto -bb↦−b 还是一一对应，故因数集合整体不变。

课件请学生用 a=50a = 50a=50 举例，并给出对照表：

bbb −50,−25,−10,−5,−2,−1,1,2,5,10,25,50-50, -25, -10, -5, -2, -1, 1, 2, 5, 10, 25, 50−50,−25,−10,−5,−2,−1,1,2,5,10,25,50
−b-b−b 50,25,10,5,2,1,−1,−2,−5,−10,−25,−5050, 25, 10, 5, 2, 1, -1, -2, -5, -10, -25, -5050,25,10,5,2,1,−1,−2,−5,−10,−25,−50

两行是同一组数，只是排列顺序相反，这正说明取相反数不改变因数集合。

◆ p.30-33｜注(2)：配对因数 a/ba/ba/b

注 (2)：当 bbb 遍历整数 aaa 的所有（非零）因数时，a/ba/ba/b 也遍历整数 aaa 的所有因数。

课件在"因数"下方标注"非零"——因为 b=0b = 0b=0 时 a/ba/ba/b 没有意义，所以这条注记必须排除 b=0b = 0b=0。以 a=50a = 50a=50 为例，课件给出对照表：

bbb −50,−25,−10,−5,−2,−1,1,2,5,10,25,50-50, -25, -10, -5, -2, -1, 1, 2, 5, 10, 25, 50−50,−25,−10,−5,−2,−1,1,2,5,10,25,50
50/b50/b50/b −1,−2,−5,−10,−25,−50,50,25,10,5,2,1-1, -2, -5, -10, -25, -50, 50, 25, 10, 5, 2, 1−1,−2,−5,−10,−25,−50,50,25,10,5,2,1

两行仍是同一组数。直观理解：因数总是"成对"出现的，bbb 与 50/b50/b50/b 相乘等于 50，一个当除数、一个当商，身份互换而已。

◆ p.34-36｜注(3)(4)(5)：零、1 与自身的整除

课件继续给出三条最常用的边界性质：

(3) 对任何整数 b≠0b \ne 0b=0，有 b∣0b \mid 0b∣0。理由：0=0⋅b0 = 0 \cdot b0=0⋅b，商取 000 即可。

(4) 对任何整数 bbb，有 1∣b1 \mid b1∣b。理由：b=b⋅1b = b \cdot 1b=b⋅1，商取 bbb 本身。

(5) 对任何整数 a≠0a \ne 0a=0，有 a∣aa \mid aa∣a。理由：a=1⋅aa = 1 \cdot aa=1⋅a，商取 111。

注意 (5) 课件写的条件是 a≠0a \ne 0a=0；其实 0∣00 \mid 00∣0 按约定也成立，但 (5) 说的"aaa 整除自己"在 a=0a = 0a=0 处是约定而非定义推论，故课件加上非零条件更严谨。

◆ p.37｜注(6)：符号不变性

注 (6)：若 b∣ab \mid ab∣a，则 b∣(−a)b \mid (-a)b∣(−a)、(−b)∣(±a)(-b) \mid (\pm a)(−b)∣(±a)。

即整除关系对给被除数或除数变号完全不变。这正是下一页例 2 要正式证明的命题，先作为观察列出。

例 2 与例 3：符号与传递

◆ p.38-41｜例 2 的证明（前半）

例 2：设 aaa、bbb 为整数，试证明：若 b∣ab \mid ab∣a，则 b∣(−a)b \mid (-a)b∣(−a)、(−b)∣(±a)(-b) \mid (\pm a)(−b)∣(±a)。

证明：若 b∣ab \mid ab∣a，根据整除的定义知，存在整数 qqq 使得

a=qba = qba=qb

因而 (−a)=(−q)b(-a) = (-q)b(−a)=(−q)b，a=(−q)(−b)a = (-q)(-b)a=(−q)(−b)，(−a)=q(−b)(-a) = q(-b)(−a)=q(−b)。

这一步只是把同一个等式 a=qba = qba=qb 用三种方式重新配对符号：把 qqq 换成 −q-q−q、把 bbb 换成 −b-b−b，等式依然成立。

◆ p.42-43｜例 2 的证明（收尾）

因 (−q)(-q)(−q) 和 qqq 都是整数，根据整除的定义知：

b∣(−a),(−b)∣a,(−b)∣(−a)b \mid (-a),\quad (-b) \mid a,\quad (-b) \mid (-a)b∣(−a),(−b)∣a,(−b)∣(−a)

即 (−b)(-b)(−b) 整除 aaa 与 −a-a−a 中的每一个，合起来就是 (−b)∣(±a)(-b) \mid (\pm a)(−b)∣(±a)，证毕。课件随后在页面下方补充一条常用推论：aaa、bbb 为整数，若 b∣ab \mid ab∣a，则 ∣b∣≤∣a∣|b| \le |a|∣b∣≤∣a∣（a≠0a \ne 0a=0 时）。理由：a=qba = qba=qb 且 a≠0a \ne 0a=0 时 q≠0q \ne 0q=0，故 ∣q∣≥1|q| \ge 1∣q∣≥1，两边乘 ∣b∣|b|∣b∣ 即得。这条是后面例 9(1) 的依据。

◆ p.44-47｜例 3：传递性的证明

例 3：设 aaa、b≠0b \ne 0b=0、c≠0c \ne 0c=0 是三个整数，试证明：若 c∣bc \mid bc∣b、b∣ab \mid ab∣a，则 c∣ac \mid ac∣a。

证明：若 c∣bc \mid bc∣b、b∣ab \mid ab∣a，根据整除的定义知，存在整数 q1q_1q1​、q2q_2q2​ 使

a=q1b,b=q2ca = q_1 b,\qquad b = q_2 ca=q1​b,b=q2​c

因而

a=q1b=q1q2ca = q_1 b = q_1 q_2 ca=q1​b=q1​q2​c

因 q1q2q_1 q_2q1​q2​ 是整数（整数的乘积还是整数），根据整除的定义知 c∣ac \mid ac∣a。

证明手法值得记住：把两条整除各翻译成一个等式，代入消去中间量 bbb，剩下的等式恰好是"aaa 等于整数倍的 ccc"，再翻译回整除记号。注意条件 b≠0b \ne 0b=0、c≠0c \ne 0c=0 保证记号 c∣bc \mid bc∣b、b∣ab \mid ab∣a 本身合法（定义要求除数非零），aaa 则不作限制。

◆ p.48-50｜定理 1.1.1 与例 4

素数与合数的定义

◆ p.192-196｜本节导览 本部分是课件第 1.1 节的第三个专题的开场。页面列出三个要讨论的要点：其一，素数（质数）与合数的基本概念；其二，素数的平凡判别方法（课件注明对应教材 1.1.4 节）；其三，筛选 nnn 以内素数的 Eratosthenes 筛法（课件注明对应教材 1.1.2 节）。这三点正好构成本讲的三个小节，先明确"什么是素数"，再解决"如何判断一个给定整数是素数"，最后解决"如何批量找出所有素数"。p.192-195 为过渡页。

◆ p.197-200｜定义 1.1.2 与例 14 定义 1.1.2：设整数 n≠0n\neq0n=0、n≠±1n\neq\pm1n=±1，如果除了 ±1\pm1±1 和 ±n\pm n±n 之外，nnn 没有其它因数，则 nnn 叫做素数（或质数或不可约数），否则 nnn 叫做合数。

这个定义是对全体非零、非 ±1\pm1±1 的整数说的，所以因数成对地取正负：例如 666 的因数有 ±1,±2,±3,±6\pm1,\pm2,\pm3,\pm6±1,±2,±3,±6，除 ±1\pm1±1 与 ±6\pm6±6 外还有 ±2,±3\pm2,\pm3±2,±3，故 6 是合数；而 777 的因数只有 ±1,±7\pm1,\pm7±1,±7，故 7 是素数。

注：当整数 n≠0n\neq0n=0、±1\pm1±1 时，nnn 和 −n-n−n 同为素数或同为合数——因为 d∣nd\mid nd∣n 与 d∣(−n)d\mid(-n)d∣(−n) 完全等价，两者的因数集合一模一样。因此在讨论中通常只取正素数，用字母 ppp 表示。

例 14：整数 2,3,5,7,11,…2,3,5,7,11,\ldots2,3,5,7,11,… 都是素数，4,6,8,9,10,12,…4,6,8,9,10,12,\ldots4,6,8,9,10,12,… 都是合数。逐一验证：4=2×24=2\times24=2×2、6=2×36=2\times36=2×3、8=2×48=2\times48=2×4、9=3×39=3\times39=3×3、10=2×510=2\times510=2×5、12=3×412=3\times412=3×4，它们都存在除 ±1\pm1±1 与自身之外的因数，全是合数；而 2,3,5,7,112,3,5,7,112,3,5,7,11 用定义检查确实没有别的因数。

页面上还留下思考题：0、1 是素数还是合数？按定义 1.1.2，该定义只对 n≠0n\neq0n=0、n≠±1n\neq\pm1n=±1 的整数有效，所以 0、1（以及 −1-1−1）既不是素数也不是合数——0 的因数包罗万象（任何非零整数都整除 0），1 的因数只有 ±1\pm1±1 与自身重合，两者都不满足定义的前提条件。这是初学者最容易出错的地方：1 不是素数，素数从 2 数起。

拓展（课件外补充）：为什么要把 1 排除在素数之外？如果 1 算素数，那么 6=2×3=1×2×3=1×1×2×36=2\times3=1\times2\times3=1\times1\times2\times36=2×3=1×2×3=1×1×2×3 就会有多种"素数分解"，后面算术基本定理"分解方式唯一"的结论就会失效。把 1 定义为"既非素数也非合数"的单位，正是为了保证分解唯一性成立。

合数的素因数：定理 1.1.6

◆ p.201-209｜定理 1.1.6 及其证明 页首提出思考：合数与其素因数的关系？由此引出定理 1.1.6：设 nnn 是一个正合数，ppp 是 nnn 的一个大于 1 的最小正因数，则 ppp 是素数，且 p≤np\le\sqrt np≤n​。

证明分两步。

第一步证 ppp 是素数（反证法）：假设 ppp 是合数，则存在整数 qqq 满足 1<q<p1<q<p1<q<p 且 q∣pq\mid pq∣p。又已知 p∣np\mid np∣n，由整除的传递性，q∣nq\mid nq∣n。这样 qqq 就是 nnn 的一个比 ppp 更小的、大于 1 的正因数，与"ppp 是 nnn 的大于 1 的最小正因数"这一假设矛盾，所以 ppp 是素数。

第二步证 p≤np\le\sqrt np≤n​：因 nnn 是合数且 p∣np\mid np∣n，可写 n=pn1n=pn_1n=pn1​，其中 n1n_1n1​ 是整数且 n1>1n_1>1n1​>1（若 n1=1n_1=1n1​=1 则 n=pn=pn=p 为素数，与 nnn 合数矛盾；若 n1<1n_1<1n1​<1 则 n<pn<pn<p 亦不可能）。若 n1<pn_1<pn1​<p，则 n1n_1n1​ 是 nnn 的大于 1 的正因数，且 n1<pn_1<pn1​<p 与 ppp 的最小性矛盾，所以 n1≥pn_1\ge pn1​≥p，即 1<p≤n1<n1<p\le n_1<n1<p≤n1​<n。于是 p2≤pn1=np^2\le pn_1=np2≤pn1​=n，故 p≤np\le\sqrt np≤n​。

拓展（课件外补充）：定理中"ppp 是大于 1 的最小正因数"措辞要精确——若不加"大于 1"，最小正因数永远是 1，定理就废了。这条定理是本讲的枢纽：它说明任何合数都能被某个不超过其平方根的素数整除，其逆否命题恰好就是下面的判别法。另外"若 n1<pn_1<pn1​<p 则矛盾"这一步，课件叙述较简，此处补全了论证细节。

◆ p.210 本页与 p.201-209 内容相同（同一证明的收尾帧，仅末行措辞由"因此"改为"故"），定理 1.1.6 的结论不变：p2≤pn1=np^2\le pn_1=np2≤pn1​=n，故 p≤np\le\sqrt np≤n​。
